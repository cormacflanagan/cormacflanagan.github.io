My research is in programming languages and software engineering, with a focus on tools and techniques for building reliable software. Much of my work addresses concurrency, including data race detection (FastTrack, RoadRunner), atomicity, and verification of concurrent programs (Anchor, Mover Logic), along with static checking (ESC/Java, Houdini), hybrid and gradual type systems, and dynamic information flow security (faceted execution).

New FlowBook: Enforcing Reproducibility in Computational Notebooks (with Stephen Freund, Emery Berger, and Eunice Jun), arXiv 2026

Current Research Earlier projects ↓

  • FlowBook: Enforcing Reproducibility in Computational Notebooks

    FlowBook is a JupyterLab extension that enforces rerun consistency: re-executing any cell from the current state would produce a result consistent with a top-to-bottom execution of the notebook, regardless of which cells have been run, modified, and rerun.

    (arXiv’26)
  • Keystone: Modular Concurrent Software Verification

    Keystone addresses the fundamental challenge of concurrent software verification: specifying and reasoning about thread interference. The project leverages a new specification notation for thread interference, embeds those specifications into a new program logic, called Mover Logic, and explores new accompanying verification techniques.

    (OOPSLA’20, ECOOP’24, Melvin demo)
  • Information Flow Control: Dynamic Enforcement of Confidentiality

    Information flow control ensures that programs cannot leak confidential data to unauthorized observers. This project developed purely dynamic enforcement mechanisms, notably faceted execution, which simulates a separate run of the program for each observer, and applied them to web browsers, database-backed applications, and serverless computing.

    (TR’21, CSF’20, CSF’19, OOPSLA’18, CCS’18, WWW’18, TOPLAS’17, PLAS’17, PLDI’16, POST’16, TR’14, PLAS’13, APLAS’12, POPL’12, STOP’11, PLAS’10, PLAS’09)
